# Original Elevated Business website archive

This directory contains the complete public website as it existed on 10 October 2026, before the business-model change.

It is intentionally excluded from Vercel deployments by the root `.vercelignore` file. The same version is also referenced locally by the Git branch `archive/original-site-2026-10-10`.

Do not remove this directory until the replacement website is complete and the archived material is no longer required.
